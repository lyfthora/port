NTS

[Construido en 2026]

React Electron TypeScript CodeMirror
Github

Creé NTS porque todas las apps de notas que existen se sentían como demasiado o muy poco. Es una app de escritorio que mantiene todo 100% local — sin registros, sin dramas de sincronización, solo tus notas en tu máquina. Viene con un editor Markdown, un canvas de dibujo para cuando las palabras no alcanzan, wiki-links para conectar ideas, importar y exportar en Markdown.
